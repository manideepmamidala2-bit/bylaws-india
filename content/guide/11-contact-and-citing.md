Every release of Bylaw One carries `CITATION.cff` and `.zenodo.json` metadata so faculty, students, and researchers can cite the exact release version (`v{{release_version}}`) and content-addressed dataset ID (`{{dataset_id}}`). ### How to cite Bylaw One

When using Bylaw One datasets, consolidated texts, parameter tables, or georeferenced zoning layers in academic research, studio briefs, or civic tools, please cite the release version and dataset identifier (see `CITATION.cff` and `.zenodo.json` in the repository root):

> **Bylaw One — Bengaluru Building Code Dataset & Consolidated Reference (Release v{{release_version}}, Dataset ID `{{dataset_id}}`, current as of {{current_as_of}}).** Stewarded by {{organisation_name}}. Source code licensed under Apache License 2.0 (`Apache-2.0`); structured datasets, parameter records, and georeferenced zoning layers licensed under Creative Commons Attribution 4.0 International (`CC BY 4.0`). Available at {{site_url}}.
